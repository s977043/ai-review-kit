## What worked

- **RCE パス PR への多重敵対レビュー**: #1434 / #1435 で security-auditor サブエージェントと gemini bot を独立に走らせ、fail-safe 欠落（orchestrator throw が ESCALATE でなくクラッシュ）とシェルインジェクション面を merge 前に捕捉・修正した。
- **default-OFF / dark-launch 規律**: #1401 の executor は二重 env ゲート（`RIVER_DETERMINISTIC_EXEC` かつ `RIVER_TRUSTED_TREE`）成立時のみ起動し、未設定なら import すらしない設計を貫徹。既定挙動不変を全 2000 テストで担保した。
- **force-push ゼロで競合解決**: dist 競合・BEHIND・分岐を ff-only merge / 空コミット / merge-not-rebase で解消し、`git reset --hard` も force-push も一切使わなかった。
- **merge 前 verify の徹底**: CI green・reviewer comment disposition・bot 再 push（head 変化）検知を毎マージで実施し、stale head のマージを回避した。
- **blast radius の大きい操作は確認**: リリース publish と branch protection 編集はユーザー承認を取ってから実行した。
