# Report Review

最終報告（完了報告）レビュー用テンプレ。**報告の質は実行の証拠ではない**。
「完了」という表現に十分な証拠があるかを疑う。

## Report Summary

- 報告が主張している内容の要約:

## Claimed Completion

- 「完了した」と主張されている項目:

## Evidence Check

- 各主張に観測可能な証拠（diff / log / PR / ファイル）が添えられているか。裏取りできたか:

## Verification Status

- 検証は実行されたか。未実行・スキップが「完了」に紛れていないか:

## Missing Details

- 具体性の欠如（変更ファイル未記載・コマンド未記載・数値の根拠なし）:

## Hidden Risks

- 報告に現れていない残リスク・副作用:

## Misleading Statements

- 誤解を招く表現（「テスト追加」だけで失敗検知力に触れない等・「はず」「思われる」）:

## Required Corrections

- 報告を承認可能にするために必要な修正・追加証跡:

## Decision

- approved / needs_revision / blocked / rejected（approve は裏取りした根拠を添える）:
