# Test cases

この差分に含まれるテストと、プランが要求するのに不足しているテストを示します。

## 追加されたテスト

- ✅ `GET /api/users/1` が `200` を返す（既存の正常系を流用）

## プランが要求するが不足しているテスト

プラン「Test requirements」より、以下が必要ですが差分に含まれていません。

- ❌ `id` が負数（例 `-1`）のとき `400` を返す
- ❌ `id` がゼロ（`0`）のとき `400` を返す
- ❌ `id` が非整数（例 `abc`）のとき `400` を返す
- ❌ 正常時レスポンスが `{ user: { id, name } }` 形式であることの検証

## 観点

既存の正常系テストは `{ user }` 形式を厳密に検証していなかったため、レスポンス形式の破壊（プラン要件 2 違反）をテストでは捕捉できていません。境界値テストの不足とあわせ、River Review は plan と tests を突き合わせてこれらを指摘します。
